# CSE574 - Intro to ML

This repository contains Jupyter notebooks for key assignments in an introductory machine learning course.

## Topics Covered

- **Data Cleaning**
  - Handling missing values, outliers, and duplicates
  - Feature scaling and encoding
  - Exploratory data analysis (EDA)

- **Regression & Classification**
  - Linear and logistic regression
  - Model evaluation metrics (accuracy, precision, recall, F1)

- **Neural Networks**
  - Basics of feedforward neural networks
  - Training with backpropagation
  - Implementation using PyTorch

- **Convolutional Neural Networks (CNNs)**
  - CNN architecture basics (conv, pooling, ReLU)
  - Implementing VGG-13 and custom CNN models using PyTorch
  - Training on image datasets

## Running the Notebooks

Clone the repo and run the notebooks in Jupyter.
